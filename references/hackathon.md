# Hackathon delivery

Write a short demo script first: concrete user/pain -> actual input -> evidence
of decision -> completed business outcome -> measured benefit. Build one complete
journey and a failure path. Use the event's rubric and rules on prior work, AI,
templates and third-party assets. Attribute prebuilt work honestly.

## Suggested allocation, not an organizer requirement

| Window | Focus |
|---|---|
| First 15% | Capability check, working channel, contract, core story |
| Next 45% | Vertical slice, continuous integration, native diagnostics |
| Next 20% | Meaningful differentiation, negative cases, final-result UX |
| Final 20% | Freeze, published-channel tests, backup recording, rehearsal/submission |

Agree typed contracts before splitting components. Avoid simultaneous edits to
the same agent files/cloud resources; assign an apply/publish owner. Multiple
coding agents and a multi-agent product are separate decisions.

## Reusable patterns

| Pattern | Benefit | Proof |
|---|---|---|
| Shared taxonomy + SharePoint + cards | Reusable data-driven UX | Filtered records and correct submitted values |
| Extract -> review -> execute | Narrow error boundary | Required confirmation before writes |
| Rulebook outside prompt | Configurable decision logic | Controlled output change after rule update |
| Structured outcomes | Reliable branching | Valid contract on every expected path |
| Analyze/write separation | Clear mutation boundary | Read-only path cannot mutate |
| Bounded enrichment | Lower payload and latency | Measured calls and output quality |
| Current data + stable guidance | Honest grounding | Sources and timestamps |

These patterns do not establish that all winners built in 24 hours or used only
standard connectors. Measure completion, correct-tool rate, grounded accuracy,
latency, manual steps and rework on a labeled sample. Label estimated benefits
and simulations. The final result card should show a business reference, status,
evidence and next action. Prefer a reliable outcome over extra agents/MCP/custom UI.
